# Neusis

> In geometry, the neusis (νεῦσις; from Ancient Greek νεύειν (neuein) 'incline towards'; plural: νεύσεις, neuseis) is a geometric construction method that was used in antiquity by Greek mathematicians.
> -- Wikipedia

Neusis is a flake-based NixOS / nix-darwin / home-manager configuration
library and the fleet config for its author's machines. It is organised in the
dendritic pattern: every file under `modules/` is a flake-parts module,
auto-imported with `import-tree`; `flake.nix` is generated by `flake-file`.

- `docs/overview.md` — how the flake is organised
- `docs/<module>/tutorial.md` — per-module guides (kalam, agent-harness, supercharged-*, hammerspoon, terminal-velocity)
- `docs/porting.md` — the engineering log of the v1 → dendritic refactor
- `cli/` — the `neusis` CLI that scaffolds a consumer repo using neusis as a library
- `old_modules/` — the complete pre-refactor tree, kept verbatim (also tagged `v1`)

## Getting started

macOS machines

```bash
darwin-rebuild switch --flake .#rogue        # or .#darwin001
```

standalone home-manager

```bash
home-manager switch --flake .#ank@rogue      # or .#kumarank@darwin001
```

build-only check

```bash
nix build .#darwinConfigurations.rogue.system
```

After changing a `flake-file.inputs` declaration:

```bash
nix run .#write-flake && nix flake update <input>
```

## Using neusis as a library

```bash
curl -fsSL https://raw.githubusercontent.com/leoank/neusis/main/cli/install.sh | sh
neusis init my-fleet
```

See `cli/README.md` and `examples/`.
