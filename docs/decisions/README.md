# Decisions

One architecture decision record per file, `ADR-0001-short-title.md`, numbered in order
and never renumbered. ADR-0002 to ADR-0014 were backfilled on 2026-11-03 from
`porting.md` and the specs; each carries the date the decision was made. A decision that changes an earlier one supersedes it; both stay.

| ADR | Decision | Status |
|-----|----------|--------|
