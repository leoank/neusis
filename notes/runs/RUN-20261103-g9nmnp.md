## Notes
Built base's `keymaps.nix` with no plugins through `makeNixvimWithModule` twice and read
`config.build.initFile`:

| variant | `/nix/store` paths | `vim.loader` | runtimepath edits |
|---|---|---|---|
| nixvim defaults (`default.lua`) | 2 (python3 and ruby hosts) | 0 | 2 (drops the config dir and its `after/`) |
| `wrapRc = false; impureRtp = true; luaLoader.enable = null; withPython3 = false; withRuby = false` (`portable.lua`) | 0 | 0 | 0 |

`portable.lua` loads in `nvim --headless --clean -u` (NVIM v0.12.4) with no error and
`<leader><space>` mapped to `<Cmd>write<CR>` (`nvim.txt`). `impureRtp = false` with
`wrapRc = false` is refused by nixvim, hence `impureRtp = true`. An earlier probe with
`luaLoader.enable = false` emitted `vim.loader.enable(false)`, which would fail on
Neovim 0.8; `null` emits nothing.

Not covered: any Neovim older than 0.12 (that needs the official release builds, planned
for CI), plugin config, and the uncommitted tree the script evaluates (`--impure`
`getFlake` of the working copy).
