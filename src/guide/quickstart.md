# Quickstart

This walk-through creates a fleet repo with one macOS laptop and one admin
user, then switches the laptop to it. Each command runs as a wizard when
you leave out the flags. The flags are shown here so you can copy them.

## 1. Scaffold the repo

```sh
neusis init my-fleet --darwin
cd my-fleet
```

```text
my-fleet/
├── flake.nix              # generated by flake-file — don't edit
├── modules/
│   ├── dendritic.nix      # flake inputs + imports neusis.flakeModules.default
│   ├── registry/home.nix  # declares the lab "home"
│   └── systems.nix        # mkNeusisFlake → nixos/darwin/homeConfigurations
└── secrets/               # agenix-rekey storage (see Secrets)
```

Every `.nix` file under `modules/` is a flake-parts module that
[import-tree](https://github.com/denful/import-tree) loads automatically.
Adding a file is enough; you don't keep an imports list. See
[Concepts](concepts.md#the-dendritic-layout).

## 2. Add a machine

```sh
neusis add machine laptop --system aarch64-darwin
```

This writes `modules/machines/laptop.nix`, which defines
`flake.neusis.machines.laptop` and adds the machine to the `home` lab.
Replace the `hostPubkey` placeholder with the host's real key
(`cat /etc/ssh/ssh_host_ed25519_key.pub`).

## 3. Add a user

```sh
neusis add user alice --full-name "Alice Example" --role admin
```

This writes `modules/users/alice.nix`, which defines
`flake.neusis.users.alice` and adds alice to the `home` lab's `admins`.
Every machine in the lab now gets an account for alice.

## 4. Give the user a home-manager setup

In `modules/users/alice.nix`, define a bundle and map it to the laptop:

```nix
{ self, inputs, ... }:
{
  flake.neusis.users.alice.hmBundles.dev = {
    imports = [ inputs.neusis.homeModules.supercharged-git ];
    neusis.supercharged-git = {
      enable = true;
      userName = "Alice Example";
      userEmail = "alice@example.org";
    };
  };

  flake.neusis.users.alice.neusisOS = {
    # … fields written by `neusis add user` …
    machineToBundlesMap.laptop = [ self.neusis.users.alice.hmBundles.dev ];
  };
}
```

## 5. Lock and switch

Nix ignores untracked files, so stage everything first. Then generate
`flake.nix` and the lock file:

```sh
git add .
nix run .#write-flake
nix flake lock
```

Switch the laptop. On a Mac that doesn't have nix-darwin yet:

```sh
sudo nix run nix-darwin -- switch --flake .#laptop
```

After that, and on every later change:

```sh
sudo darwin-rebuild switch --flake .#laptop      # macOS
sudo nixos-rebuild switch --flake .#myhost       # NixOS
home-manager switch --flake .#alice@laptop       # standalone home-manager
```

`mkNeusisFlake` produces a `<user>@<host>` home configuration for every
user who has a `machineToBundlesMap` entry for that host. Use it on
machines where you don't manage the system.

> **NixOS hosts with login users** need `initialHashedPassword` set to an
> agenix secret before they evaluate. See [Secrets](secrets.md).
